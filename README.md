# School Van Management System

A web-based dashboard for managing school vans, drivers, students and payments.

## Features
- Van Management
- Driver Management
- Student Management
- Payment Tracking
- Voice Search
- Multi Language Support
- Supabase Cloud Database
- Responsive Design

## Technologies Used
- HTML
- CSS
- JavaScript
- Supabase
- Netlify
